Descripcion:

- La aplicación web fue desarrollada para que los clientes (usuarios) del barbero (administrador) puedan solicitar turnos de manera más eficiente y organizada. Cada usuario puede registrarse e iniciar sesión para realizar la reserva de turnos, pero solo puede reservar un turno por día. Esto optimiza el flujo de trabajo del barbero y evita que los clientes pierdan el registro de las fechas y horarios que han reservado. Por su parte, el barbero cuenta con un panel de administración que le permite agregar o eliminar horarios, así como ver y cancelar los turnos de aquellos clientes que deseen darse de baja.


Tecnologías utilizadas

- Lenguajes: Python, JavaScript
- Framework: Django
- Desarrollo Frontend: HTML y CSS
- Base de datos: SQLite


Instrucciones de instalación:

- Asegúrate de tener Python 3.8 o superior instalado (python --version)
- Instalacion de Django (pip install django)


Ejecucion Barberia:

- Abrir el proyecto desde Visual Studio Code
- Abrir terminal y ubicarse en la carpeta del proyecto (cd barberia)
- Ejecutar el servidor (python manage.py runserver)
- Abrir en el navegador la URL (Starting development server at "http://127.0.0.1:8000/")
- Para ingresar al apartado de admin copiar abrir el mismo navegador agregando (/admin) al final
